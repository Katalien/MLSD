# Репозиторий для курса MLSD
## Студентка: Зинякова Екатерина
## Проект: Система автоматической проверки документов

Система автоматической проверки пакетов банковских документов (досье): сервис сравнивает подписи и печати на проверяемых документах с эталонами из самого пакета и проставляет статусы по каждой проверке, каждому документу и пакету в целом.

## Зачем нужен проект

Сейчас оператор проверяет каждый пакет вручную: сопоставляет подписи и печати с эталонными, проверяет комплектность и данные клиента. Автоматизация должна ускорить проверку и снизить нагрузку на операторов. Заказчику важнее всего, чтобы проверки, признанные пройденными, были действительно верными, поэтому пакеты, прошедшие автоматическую проверку, не потребуют ручной проверки, а остальные будут передаваться оператору.

Подробное описание целей, требований, скоупа итерации, постановки задачи и блок-схем приведено в дизайн-документе: [docs/ml_system_design_doc.md](docs/ml_system_design_doc.md).

## Что делает сервис

Сервис принимает пакет документов клиента (юридического лица или ИП) и выполняет проверки:

- комплектность пакета, отсутствие дубликатов, ограничения MVP (правила);
- определение эталонов подписи и печати (КОПОП, акцепт к КОПОП, паспорт);
- поиск подписей и печатей на документах (детекция, YOLO);
- сравнение подписей и печатей с эталоном по визуальному сходству (метрическое обучение: DINOv3 для печатей, ResNet50 для подписей) с оценкой сходства по шкале 0–100;
- в последующих итерациях: сверка реквизитов печати (ИНН, ОГРН, наименование) и ФИО с данными выписки ЕГРЮЛ/ЕГРИП (Qwen3-VL через vLLM).

Результат содержит статусы по каждой проверке, по каждому документу и общий статус пакета: `ok` (всё в порядке), `partial` (есть предупреждения), `error` (критическая ошибка), а также пояснения и время обработки.

## Ограничения

- Закрытый контур банка: документы содержат персональные данные, поэтому используются только локальные модели, внешние API не применяются.
- Объём памяти GPU не более 20 ГБ.
- Время обработки одного пакета не более 2 минут.
- Поддерживаются только юридические лица и ИП.

## Технологии

Python 3.9+, Apache Kafka (вход и выход), S3-совместимое хранилище (документы), YOLO, DINOv3, ResNet50, Qwen3-VL (vLLM), ONNX.
